# Типовые схемы планов эталона МГИМО — описание для генератора

Источник: выгрузка `plan_dump/` (`tools/plan_geometry.py`, 24 листа), разобрана 2026-11-08. Координаты — мм бумаги (листы 1:40 — A3 альбомный 420×297; 1:48 — A3 книжный 297×420). Дополняет `docs/AGENT_TASKS.md` (раздел 4.4) и `docs/REQUIREMENTS.md`.

## 1. Семейства листов
Для каждого защищаемого помещения в эталоне **три листа**:

| Семейство | Название листа | Файлы выгрузки | Назначение |
|---|---|---|---|

| **F2** | «Схема расположения модулей, трубопровода АГПТ и прокладки интерфейса» | `1A_01, 1A_04, 5A_01, 4_00, 4_02, 4_04, 4_06` | Метка модуля `1МРТ1…7МРТ1`, развёртка трубопровода с размерами, насадки, вид модуля с принадлежностями, фрагмент плана, детали крепления, таблица обозначений |
| **F3** | Расчётная схема + таблицы расчёта | `2_06, 2_09, 2_10, 2_11, 2_12, 2_17` | Схема участков с Ø, «Результаты расчетов», «ТРУБОПРОВОДНАЯ РАЗВОДКА» |

## 3. Состав листа F2 (схема модулей и трубопровода), координаты на примере `5A_01`
1. **Развёртка трубопровода** — слой `АГПТ`, полилинии цвет 244, вес 50–70, вершины задают участки под реальными углами; размеры (`DIMENSION`, стиль `Standard`) подписывают длины в мм; на конце каждой ветки блок `360 NOZZLE` (слой `JAM NOVEC SYSTEM PIPING`, масштаб −1, поворот 89°) и выноска «Насадок распылитель на основное помещение» / «под фальшь полом». Для 1117: 3610, 1851, 150, 1500, 150, 4700, 1851, 1500, 100, 100.
2. **Фрагмент плана** в рамке 75×100 мм (слой `0`, замкнутая полилиния), внутри контур модуля, цветные линии кабелей, метка модуля (`GOST Common`, h 3,75), метки `А3`, `СС1`, выноска `RS1`.
3. **Вид модуля сбоку** (слой `0`, цвет 1) с выносками: «МПТГ «Proffex» (66-50-32)», `ЭКМ`, `СДУ`, `РВД`, «Электромагнитное ПУ с ручным пуском», «Распределительный трубопровод». Набор зависит от типоразмера (у 66-180-50 нет ПУ на листе 1435).
4. **Детали крепления** (слои `SM_kelepçe`, `FM`, `ось`, `0`, окружность r = 7,1 мм): библиотечный фрагмент, одинаковый на всех листах F2; сегмент `FM` повторяется с наложением (дубли линий — не копировать).
5. **Выноски обстановки** (шрифт ISOCPEUR, h 2,5): «ЖБ плита», «НКТ», «Трубопровод», «RS1».
6. **Таблица «Условные обозначения»** 6×3 (колонки 16,3 / 9,9 / 73,9), позиция (314,9; 292,0).
7. **Подпись листа**: слой `4.4.4._Сэндвич`, ARIAL h 2,5: «Фрагмент плана … Помещение … Схема расположения модулей, трубопровода АГПТ и прокладки интерфейса».

## 6. Наблюдения и ловушки эталона (не копировать)
1. **Одинаковые размеры трубопровода в разных помещениях.** Для 1117, 1215, 1313 и 1414 на листах F3 одни и те же числа (3610, 1851, 150, 1500, 150, 4700, …), хотя высоты помещений разные (3,85 и 4,75 м). Похоже на шаблон. Генератор должен считать длины по геометрии, а инженер проверять.
2. **Опечатки в тексте:** «Условно-ргафические обозначения», «лектпропитания», «пожаротушеия», «этада», «Насадок … под фальшь полом» (падеж). В выходе исправлять.
3. **Заголовок `4_06`** содержит «Помещение кроссовой», но размеры и Ø совпадают с расчётом 1435 (архив): ошибка эталона.
4. Лист F1 для 1435 (`4_05`) содержит только часть выносок (без извещателей): состав зависит от помещения, правила пока неизвестны.
5. Таблица «Условные обозначения» в F1 содержит символы блоков (`An`, `UGn`, `PU-PT`, `yBTHz.n` …) — это имена атрибутов/символов, в библиотеке они должны быть реальными блоками.

## 7. Что ещё нужно для полной автоматизации
1. **Библиотека фрагментов**: собрать из `plan_dump` определения (детали крепления, вид модуля ×3, блоки `360 NOZZLE`, `Геркон`, легенды) в один файл-библиотеку блоков (скрипт `tools/build_fragment_library.py`, следующий шаг).
2. **Правило построения развёртки трубопровода**: как по геометрии помещения (высота, фальшпол, положение модуля, зоны насадков) получаются участки 3610 / 1851 / 1500 / 4700 и положение насадков; данных эталона недостаточно, нужен метод инженера (вопрос владельцу).
3. **Правило подбора состава выносок F1** по типу помещения (серверная, кроссовая, архив).
4. **Подоснова**: источник стен и осей в новом проекте (чертёж заказчика): как плагин получает контуры помещений.
