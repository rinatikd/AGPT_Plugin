## Цель
Плагин, который помогает **автоматически рассчитывать и строить систему АГПТ/АППТ**: по помещениям из модели считает массу ГОТВ и гидравлику, строит модули, трубопроводную разводку, насадки на плане и выпускает листы проекта по эталону МГИМО.

## Порядок работ
1. **Расчёт (движок).** Привести расчёт к контрольным примерам `tests/golden/mgimo_calc_golden.json`. Нормативная база — строительные нормы и правила Республики Казахстан (СН РК 2.02-11-2002, СП РК 2.02-102-2022, СН РК 2.02-02-2023, так заявлено на листе «Общие данные» эталона). Каталог модулей — `tests/golden/modules_proffex.json`. *Приёмка:* Mp для помещений 1016, 1020, 1117, 1215/1313, 1414 совпадает с эталоном в пределах 1% при заявленных исходных данных; 1435 помечен как аномалия.
2. **Построение системы на плане.** Из зоны: подбор модулей (каталог), трассировка разводки, расстановка насадков, диаметры участков, выноски/размеры, слой `АГПТ`. Для геометрии планов нужна отдельная выгрузка (пакет P6).
3. **Гидравлика.** Таблица участков: диаметр, длина, перепад высот, давление перед насадком, площадь отверстий насадка, время выхода 95% ГОТВ. Контрольные данные — таблицы «ТРУБОПРОВОДНАЯ РАЗВОДКА» в `sheets_dump` (разобрать в машиночитаемый вид).
4. **Содержание листов.** Таблицы «Исходные данные», «Результаты расчетов», «Трубопроводная разводка», спецификация, общие данные — по каталогу эталона (раздел 4.4 задания), заполняются из движка расчёта.

## Что выяснено по расчёту (исправлено 2026-11-04)
Методика заявлена на листах эталона «Общие данные (продолжение)» и «Промежуточные расчеты».

**Заявленные исходные данные:** ГОТВ Хладон 227еа; ρ0 = 7,28 кг/м³ при 293 К; Cн = 7,2%; τпод = 10 с; высота над уровнем моря 893 м; Π = 0,65; заполняемость баллона 1,1; газ-вытеснитель азот.

**Формулы на листе:** ρ1 = ρ0·T0/TM·K3; δ = ΣFн/Vp; K2 = Π·δ·τ·√H; Mтр = Vтр·ρГОТВ; Mг = K1·[Mp + Mтр + Mбn]. Формула Mp на листе — графический объект, текстом не читается.

**Что подобрано по цифрам эталона (требует подтверждения по тексту нормы):**
- K3 ≈ 0,9604 (ρ1 = 6,992 при 20 °C, то есть 7,28·K3; для 17 °C получается 7,065).
- Mp = **1,5**·V·ρ1·(1+K2)·Cн/(100−Cн), V = S·H. При заявленных исходных данных это даёт отклонение 0,00% (1215, 1313, 1414), 0,03% (1117), 0,08% (1020), 0,5% (1016). Для 1435 «Книгохранилище» отклонение −12% (аномалия эталона).
- Логарифмическая форма Mp = V·ρ1·(1+K2)·ln(100/(100−Cн)), которая сейчас в коде плагина, при Cн = 7,2 даёт массу примерно на **36% меньше** эталона на всех помещениях. Это главное расхождение, его исправлять первым.

**Прежние константы плагина** (ρ0 = 7,28, Cн = 7,2) верны и совпадают с эталоном. Расходятся: форма формулы Mp (нет множителя 1,5 и линейного вида), поправка K3 на высоту, температура по умолчанию (25 °C вместо 20/17 °C).

**Мтр:** Mтр = 1,195·Vтр. При Vтр в м³ получается ~0,003 кг, что нереально мало. Единицы не выяснены, на выбор модуля это влияет. Вопрос инженеру.

**Подбор модуля:** каталог МПТГ «Proffex» 28/42/50/184/192 кг. Правило «наименьший типоразмер с заправкой ≥ Mp+Mтр» подтверждается на 1016, 1215/1313, 1414; для 1117, 1020 и 1435 расхождения на килограммы или на один типоразмер.
