# Приоритеты проекта (решение владельца, 2026-11-03)

## Цель
Плагин, который помогает **автоматически рассчитывать и строить систему АГПТ/АППТ**: по помещениям из модели считает массу ГОТВ и гидравлику, строит модули, трубопроводную разводку, насадки на плане и выпускает листы проекта по эталону МГИМО.

## Что НЕ приоритет
Оформление рамки и штампа (блок `blocks/MMX_ШТАМП.dwg`) оставить как есть, не переделывать. Важно содержание листов.

## Порядок работ
1. **Расчёт (движок)** — по `docs/CALC_SPEC_RK.md` (методика СП РК 2.02-102-2022, Приложение Г; проверена на всех помещениях эталона) с учётом решений владельца ниже. Контрольные примеры: `tests/golden/mgimo_calc_golden.json`; каталог модулей: `tests/golden/modules_proffex.json`.
2. **Построение системы на плане.** Из зоны: подбор модулей (каталог), трассировка разводки, расстановка насадков (в т. ч. под фальшпол), диаметры участков, выноски/размеры, слой `АГПТ`. Для геометрии планов нужна отдельная выгрузка (пакет P6, `tools/room_geometry.py`).
3. **Гидравлика.** Таблица участков: диаметр, длина, перепад высот, давление перед насадком, площадь отверстий насадка, время выхода 95% ГОТВ. Контрольные данные — таблицы «ТРУБОПРОВОДНАЯ РАЗВОДКА» в `sheets_dump`.
4. **Содержание листов.** Таблицы «Исходные данные», «Результаты расчетов», «Трубопроводная разводка», спецификация, общие данные — по каталогу эталона (раздел 4.4 задания), из движка расчёта.
5. **Оформление (стили, слои, ACAD_TABLE).** После пунктов 1–4. Рамку/штамп не менять.

## Что установлено по расчёту
Подробно — `docs/CALC_SPEC_RK.md`. Таблицы эталона посчитаны строго по СП РК: формула Г.3 для сжиженных газов `Mр = K4·Vр·ρ1·(1+K2)·Cн/(100−Cн)`, K4 = 1,5 для пожаров класса А (Г.7), ρ0 = 7,28, Cн = 7,2%, K3 = 0,96, τпод = 10 с, K1 = 1,05; отклонение 0,02–0,55% на шести помещениях. Формула с `ln` на листе эталона — Г.4 для сжатых газов, напечатана ошибочно. Плагин сейчас использует `ln`, K4 = 1,05, K3 = 1,0, Mтр по плотности жидкости: масса занижена примерно в 2,4 раза (список расхождений — раздел 6 CALC_SPEC_RK).

## Решения владельца (2026-11-06)
1. **Высота над уровнем моря — высота Астаны** (около 347 м). Высота — параметр проекта, по умолчанию Астана. K3 по таблице Д.11 между строками 300 м (0,96) и 600 м (0,93): **в норме правило интерполяции не оговорено** (в CALC_SPEC_RK п. 3 это предположение). Консервативный и совпадающий с эталоном вариант — строка 300 м, K3 = 0,96 (при интерполяции 0,955). Реализовать выбор «ближайшая нижняя строка (по умолчанию) / интерполяция».
2. **Архив / книгохранилище (1435): K4 = 2,25** (бумага в папках/рулонах). Расчёт при K3 = 0,96: Mр ≈ 237 кг при Vр = S·H = 194,2 м³ и ≈ 270 кг при Vр = 221 м³ (как в эталоне); Mг (K1 = 1,05, без Mтр и Mбn) ≈ 249 и ≈ 283 кг. Это больше любого одного модуля каталога (192 кг): нужна установка из нескольких модулей, правило подбора набора (число модулей, минимум суммарной заправки) утвердить. Эталон с K4 = 1,5 даёт Mг ≈ 189 кг → модуль 192 (в эталоне 191), то есть для архива эталон занижен относительно нормы.
3. **Помещение 1117 (серверная):** на плане «Фальшь пол», насадки стоят и «на основное помещение», и «под фальшпол». Поэтому Vр = 57 м³ включает подпольное пространство (12 м² × 4,75 м), а в K2 берётся высота основного помещения 3,85 м. Расчётный объём и высота для K2 должны быть **двумя независимыми входами**. Площадь по чертежу уточняется выгрузкой `tools/room_geometry.py` (таблица эталона: 12,00 м²).
4. **Mтр — реалистично, по СП РК.** Норма (Г.2) определяет `Mтр = Vтр·ρготв`, где ρготв — плотность остатка ГОТВ при давлении в трубопроводе после окончания истечения Mр (формулы ρготв в тексте нормы нет). Принять: ρготв = плотность паров ГОТВ при остаточном давлении, но не выше плотности насыщенных паров при Tм (для хладона 227еа при 20 °C порядка 27–32 кг/м³, справочно, подтвердить по паспорту ГОТВ); остаточное давление — из гидравлического расчёта (давление в трубе в конце выпуска). Ожидаемый порядок Mтр для Vтр = 0,0027–0,025 м³: 0,07–0,7 кг (в эталоне 0,003–0,03 кг, в плагине сейчас 3,8–36 кг). Плотность жидкой фазы (1400 кг/м³) для остатка не применять. Окончательную формулу ρготв и источник данных (паспорт модуля/ГОТВ) утверждает владелец.
