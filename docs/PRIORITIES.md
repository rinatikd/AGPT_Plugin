## Цель
Плагин, который помогает **автоматически рассчитывать и строить систему АГПТ/АППТ**: по помещениям из модели считает массу ГОТВ и гидравлику, строит модули, трубопроводную разводку, насадки на плане и выпускает листы проекта по эталону МГИМО.

1. **Расчёт (движок).** Нормативная база по эталону — нормы Республики Казахстан (СН РК 2.02-11-2002, СП РК 2.02-102-2022, СН РК 2.02-02-2023); структура методики совпадает с Приложением Д СП 485.1311500.2020 (ред. Движок делать **параметрическим**: вид формулы Mp, множитель, Cн, ρ0, K3, K1 — настройки, а не константы в коде (см. «Нерешённое» ниже).

4. **Содержание листов.** Таблицы «Исходные данные», «Результаты расчетов», «Трубопроводная разводка», спецификация, общие данные — по каталогу эталона (раздел 4.4 задания), из движка расчёта.

## Что установлено по расчёту (обновлено 2026-11-04)

### Заявлено в эталоне (лист «Общие данные (продолжение)», скриншот владельца)
Хладон 227еа; ρ0 = 7,28 при 293 К; Cн = 7,2%; τпод = 10 с; высота 893 м; заполняемость баллона 1,1; газ-вытеснитель азот. Формулы на листе: ρ1 = ρ0·T0/Tм; δ = ΣFн/Vp; K2 = Π·δ·τпод·√H; Mтр = Vтр·ρГОТВ; **Mp = Vp·ρ1·(1+K2)·ln(100/(100−Cн))**; Mг = K1·[Mp + Mтр + Mбn].

### Расхождение внутри эталона
Цифры таблиц «Результаты расчетов» **не получаются** по формуле, напечатанной на листе (с логарифмом). Они воспроизводятся (0,00–0,5% на 5 из 6 помещений) формулой Mp = **1,5**·Vp·ρ1·(1+K2)·Cн/(100−Cн) с ρ1 = ρ0·K3·T0/Tм, K3 ≈ 0,9604. Напечатанная форма с Cн = 7,2 даёт массу на ~36% меньше таблиц. Происхождение множителя 1,5 неизвестно.

### Что говорит норма (СП 485.1311500.2020, Приложение Д, ред. Изм. № 2 от 26.05.2026, текст с consultant.ru; сами формулы там картинками и мной не прочитаны)
- Мг = K1·[Mр + Mтр + Mбn], **K1 = 1,05** (Д.2.1).
- Формула Mр **зависит от вида ГОТВ**: отдельная для «сжиженных газов, за исключением CO₂» и отдельная для «сжатых газов и CO₂». Хладон 227еа — сжиженный газ. Вид формулы для сжиженных газов (линейная Cн/(100−Cн) или с логарифмом) по тексту не подтверждён: нужна сверка с нормой/ГОСТ Р 53281.
- K3 берётся из таблицы Г.17 (высота над уровнем моря), ρ1 = ρ0·T0/Tм·K3.
- K2 = П·δ·τпод·√H; П = 0,65 при проёмах в нижней (до 0,2H) и верхней (от 0,8H) зонах примерно поровну; 0,1 — только верх; 0,25 — только низ; 0,4 — остальные случаи.
- Mтр = Vтр·ρост, где ρост — плотность остатка при давлении в трубопроводе после выпуска (зависит от Pн и Pа = 0,1 МПа; Pн рекомендовано 0,6–1,0 МПа для ГОТВ кроме CO₂); Vтр включает объём труб и сосудов. В эталоне Mтр = 1,195·Vтр, что на порядки ниже ожидаемого по норме.
- Mбn = остаток в модуле Mб (по ТД) × число модулей n.
- Cн для пожара подкласса A2 равна нормативной концентрации по н-гептану (7,2% для 227еа). Для подкласса A1 (кроме тлеющих): Mр = K4·Mр-гепт, K4 = 1,2; 1,3 для бумаги, картона, тканей в кипах/рулонах/папках; 2,25, если доступ пожарных после срабатывания исключён; параметр негерметичности для A1 не более 0,001 м⁻¹.
- Для РФ с 26.07.2026 действует Изменение № 2 к СП 485; в эталоне заявлены нормы РК, актуальную версию РК нужно сверить.
