# Приоритеты проекта (решение владельца, 2026-11-03)

Заменяют порядок работ из раздела 6 `docs/AGENT_TASKS.md`. Остальные разделы задания (эталон, каталог листов, расхождения кода) остаются в силе.

## Цель
Плагин, который помогает **автоматически рассчитывать и строить систему АГПТ/АППТ**: по помещениям из модели считает массу ГОТВ и гидравлику, строит модули, трубопроводную разводку, насадки на плане и выпускает листы проекта по эталону МГИМО.

## Что НЕ приоритет
Оформление рамки и штампа (блок `blocks/MMX_ШТАМП.dwg`) оставить как есть, не переделывать. Важно содержание листов.

## Порядок работ
1. **Расчёт (движок)** — по `docs/CALC_SPEC_RK.md` (методика СП РК 2.02-102-2022, Приложение Г; проверена на всех помещениях эталона). Контрольные примеры: `tests/golden/mgimo_calc_golden.json`; каталог модулей: `tests/golden/modules_proffex.json`.
2. **Построение системы на плане.** Из зоны: подбор модулей (каталог), трассировка разводки, расстановка насадков, диаметры участков, выноски/размеры, слой `АГПТ`. Для геометрии планов нужна отдельная выгрузка (пакет P6).
3. **Гидравлика.** Таблица участков: диаметр, длина, перепад высот, давление перед насадком, площадь отверстий насадка, время выхода 95% ГОТВ. Контрольные данные — таблицы «ТРУБОПРОВОДНАЯ РАЗВОДКА» в `sheets_dump`.
4. **Содержание листов.** Таблицы «Исходные данные», «Результаты расчетов», «Трубопроводная разводка», спецификация, общие данные — по каталогу эталона (раздел 4.4 задания), из движка расчёта.
5. **Оформление (стили, слои, ACAD_TABLE).** После пунктов 1–4. Рамку/штамп не менять.

## Что установлено по расчёту (обновлено 2026-11-04, после чтения СП РК 2.02-102-2022)
Подробно — `docs/CALC_SPEC_RK.md`. Кратко:
- Таблицы эталона посчитаны **строго по СП РК**: формула Г.3 для сжиженных газов `Mр = Vр·ρ1·(1+K2)·Cн/(100−Cн)`, **K4 = 1,5** для пожаров класса А (Г.7), ρ0 = 7,28, Cн = 7,2%, K3 = 0,96 (таблица Д.11), τпод = 10 с, K1 = 1,05. Отклонение от таблиц эталона 0,02–0,55% на всех шести помещениях. Моё прежнее предположение «множитель 1,5 подобран» отменяется: это K4 из нормы.
- Формула с `ln`, напечатанная на листе эталона, — это Г.4 для сжатых газов и CO₂. На листе она напечатана ошибочно, цифры считали по Г.3.
- Плагин сейчас использует `ln` (Г.4) и K4 = 1,05, не учитывает K3 (1,0), П всегда 0,65, нет Mбn, Mтр считается по плотности жидкости. Из-за формулы с `ln` и отсутствия K4 = 1,5 масса Mр занижена примерно в 2,4 раза относительно эталона и нормы. Список расхождений и требований к движку — в разделах 6 и 7 `docs/CALC_SPEC_RK.md`.

### Нерешённое (нужен инженер)
1. Лист эталона заявляет «высота 893 м», а K3 = 0,96 соответствует 300 м (для 893 м по таблице Д.11 ≈ 0,89). Астана около 350 м. Какую высоту и K3 принимать для новых проектов?
2. Помещение 1435 (архив/книгохранилище): в эталоне K4 = 1,5 и объём около 221 м³ (S·H = 194 м³). Если бумага в папках/рулонах, по норме K4 = 2,25 и масса Mр выходит за самый крупный модуль 192 кг.
3. Помещение 1117: Mр посчитана на V = 57 м³ (H = 4,75), δ и K2 — как при H = 3,85. Согласовать объём и высоту.
4. Mтр: единицы и значение ρготв (в эталоне Mтр = 1,195·Vтр, нереально мало), Mб и n.
5. Подбор модуля по каталогу (28/42/50/184/192 кг): «наименьший ≥ Mг» подтверждён не везде.

### Правила для агентов
Константы ГОТВ (ρ0 = 7,28, Cн = 7,2) верны. Менять расчёт в плагине по `docs/CALC_SPEC_RK.md`, а не подгонять под таблицы эталона. Любое отклонение от нормы — только явной настройкой проекта с записью в отчёт расчёта.
