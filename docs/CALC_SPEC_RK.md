# Расчёт массы ГОТВ по СП РК 2.02-102-2022 (Приложение Г) — спецификация для движка плагина

Источник: СП РК 2.02-102-2022 «Пожарная автоматика зданий и сооружений» (файл передан владельцем, 339 стр.): Приложение Г (методика, стр. 84–86 документа), Приложение Д (параметры ГОТВ, таблицы Д.8 и Д.11), Приложение Е (площадь сбросного проёма), п. 5.4 (время подачи). Это норма, на которую ссылается эталон МГИМО (лист «Общие данные (продолжение)»). Формулы ниже переписаны с текста нормы; значения проверены на всех помещениях эталона.

## 1. Формулы (Приложение Г)
- **Г.1** `Mг = K1·(Mр + Mтр + Mб·n)`; **K1 = 1,05** (Г.2).
- **Г.2** `Mтр = Vтр·ρготв` — ρготв: плотность остатка ГОТВ при давлении в трубопроводе после окончания истечения Mр (формулы для ρготв в тексте нормы нет, это расчётный параметр проекта).
- **Mб·n** — остаток ГОТВ в модуле Mб (по эксплуатационным документам на модуль) × число модулей n.
- **Г.3** для **сжиженных газов, кроме CO₂** (хладон 227еа в модулях с газом-вытеснителем — сжиженный газ): `Mр = Vр·ρ1·(1+K2)·Cн/(100−Cн)`.
- **Г.4** для **сжатых газов и CO₂**: `Mр = Vр·ρ1·(1+K2)·ln(100/(100−Cн))`.
- **Г.5** `ρ1 = ρ0·(T0/Tм)·K3`, T0 = 293 К, Tм — минимальная температура воздуха в помещении (К), K3 по таблице Д.11.
- **Г.6** `K2 = П·δ·τпод·√H`, `δ = ΣA/Vр`.
  П = 0,65 (проёмы в нижней 0–0,2H и верхней 0,8–1,0H зонах примерно поровну, или на потолке и на полу); 0,10 (только верх); 0,25 (только низ); 0,4 (равномерно и во всех остальных случаях).
- **Г.7 (пожары класса А):** `Mр = K4·Mр-гепт`, где Mр-гепт считается по Г.3/Г.4 при нормативной концентрации по н-гептану; **K4 = 2,25** — бумага, гофрированная бумага, картон, ткани и т. п. в кипах, рулонах или папках; **K4 = 1,5** — для других пожаров класса А. Параметр негерметичности для класса А не более **0,001 м⁻¹**. Для помещений, в которые исключён доступ пожарных после срабатывания, применяют CO₂ с коэффициентом 2,25.
- Примечание 1 к Г.1: если объём (склады, хранилища, гаражи) или температура заметно колеблются, брать максимальный объём и минимальную температуру.

## 2. Параметры хладона 227еа (Приложение Д)
- ρ0 = **7,28 кг/м³** при 293 К и 101,3 кПа.
- Cн (таблица Д.8): н-гептан **7,2%**; толуол 6,0%; бензин А-76(80) 7,3%; растворитель 647 7,3%.
- Время подачи τпод = **10 с** (модульные установки, в которых применяются сжиженные газы, кроме CO₂).

## 3. Таблица Д.11 — поправка K3 на высоту над уровнем моря
0 м — 1,00; 300 — 0,96; 600 — 0,93; 900 — 0,89; 1200 — 0,86; 1500 — 0,82; 1800 — 0,78; 2100 — 0,75. Между точками линейная интерполяция.

## 4. Площадь сбросного проёма (Приложение Е)
`Ac ≥ K4·K5·Mр / (0,7·K1·τпод·ρ1) · ρв / √(7·10⁶·Pa·[((Pпр+Pa)/Pa)^0,2857 − 1]) − ΣA`; K4 здесь = 1,2 (запас, это другой K4, чем в Г.7), K5 = 1 для сжиженных газов; Pпр — допустимое избыточное давление, МПа; Pa — атмосферное, МПа; ρв — плотность воздуха. Если правая часть ≤ 0, проём не нужен.

Формула с логарифмом, напечатанная на листе «Общие данные (продолжение)», — это Г.4 для сжатых газов; на листе она напечатана ошибочно, считали по Г.3.

Что остаётся неясным в самом эталоне (вопросы инженеру, в код не подгонять):
1. **«Высота над уровнем моря 893 м»** на листе, а K3 = 0,96 соответствует 300 м (по таблице Д.11 для 893 м получилось бы ≈ 0,89). Астана расположена около 350 м, значит K3 ≈ 0,955 по интерполяции; в эталоне взято 0,96.
2. **1435 «Книгохранилище (архив)»**: эталон взял K4 = 1,5 и объём около 221 м³ (по S·H получается 194,2 м³). Если в архиве бумага в папках/рулонах, норма требует K4 = 2,25: Mр вырастет примерно до 237–270 кг, больше самого крупного модуля 192 кг. Нужно решение инженера.
3. **1117 «Серверная»**: Mр посчитана на V = 57 м³ (H = 4,75), а δ и K2 — как при H = 3,85. Объём и высота должны быть согласованы.
4. **Mтр** в эталоне = 1,195·Vтр (≈ 0,003 кг) — нереально мало; значение ρготв нужно определить.
5. **Mг**: подбор модуля по каталогу (`tests/golden/modules_proffex.json`); правило «наименьший модуль ≥ Mг» подтверждено не везде.

## 6. Расхождения нынешнего расчёта плагина (`src/AGPT_Plugin_Drawings.cs`, класс `Calc`, около строк 1250–1300) с нормой
1. **Форма Mp.** Плагин использует `ln` (Г.4, формула для сжатых газов и CO₂). Для хладона 227еа нужна Г.3 (линейная Cн/(100−Cн)).
2. **K4.** В плагине K4 = 1,05 по умолчанию для всех зон и умножает Mp. По норме K4 — коэффициент вида горючего: 1,5 (класс А, прочее), 2,25 (бумага в кипах/рулонах/папках), для класса В (н-гептан) K4 не применяется. Значение 1,05 в норме нет.
3. **K3.** В плагине K3 = 1,0. Нужно брать по таблице Д.11 по высоте объекта (для Астаны ≈ 0,955–0,96).
4. **П.** Константа 0,65. Нужен выбор из 0,65 / 0,1 / 0,25 / 0,4 по расположению проёмов.
5. **Mтр.** В плагине `Vтр·1400` (плотность жидкой фазы) или `Vтр·ρ1·2,5`, что больше. Норма требует плотность остатка при давлении в трубе после выпуска; расчёт должен принимать ρготв как параметр.
6. **Mбn** в плагине нет.
7. **Tм.** По умолчанию 25 °C; норма требует минимальную температуру воздуха (в эталоне 20 или 17 °C).
8. **Vp.** В плагине объём берётся отдельно (хорошо), но в эталоне Vp может отличаться от S·H (1435); поле «расчётный объём» должно быть самостоятельным вводом с примечанием.
9. **Проверка δ ≤ 0,001 м⁻¹** для класса А отсутствует.
10. **Округление.** Плагин округляет Mг вверх до целых кг; в эталоне подбирается модуль из каталога. Округление и подбор модуля — отдельные шаги.
11. **K1 = 1,05** и **Cн = 7,2%**, **ρ0 = 7,28**, **τпод = 10 с** — верны.
12. **Сбросной проём** (КСИД) считается упрощённо по Бернулли с Pпр = 5 кПа; норма (Е.1) использует адиабатическую форму и коэффициенты K1, K4 = 1,2, K5. По порядку величины близко, но формулу нужно заменить на Е.1.

## 7. Требования к движку расчёта
- Параметры ГОТВ (ρ0, Cн по горючему материалу, вид газа «сжиженный/сжатый/CO₂», τпод) — в справочнике ГОТВ с указанием таблицы нормы.
- Выбор формулы Mр по виду газа: сжиженный → Г.3, сжатый/CO₂ → Г.4.
- Вход зоны: Vр (расчётный объём), H, ΣA, положение проёмов (→ П), Tм, высота объекта (→ K3), класс/материал горючего (→ K4), Vтр, ρготв, Mб, n.
- Выход: ρ1, δ, K2, Mр-гепт, K4, Mр, Mтр, Mбn, Mг, подобранный модуль, площадь сбросного проёма.
- Тесты: `tests/golden/mgimo_calc_golden.json`, допуск 1% по Mр (кроме помечено аномальных входов, см. п. 5).
- Любое отклонение от нормы (множитель, переопределение K3 и т. п.) — явная настройка проекта с записью в отчёт расчёта.
