# Устройства, кабели и кабельный журнал (КЖ)

Основание: решения владельца (2026-11-12), типовые листы F1 эталона МГИМО (`docs/PLAN_SCHEMES.md`). Дополняет `docs/REQUIREMENTS.md`.

## 1. Решения владельца
1. **КЖ — кабельный журнал** (кабели АПС, ТТ, интерфейс). Лист **обязателен** в комплекте (заменяет прежнее «необязателен, по флагу» из REQUIREMENTS, пункт C3, принятое без учёта значения КЖ). Собирается из кабельных линий на плане и таблицы F1.
2. **Плагин автоматически расставляет устройства и кабельные линии** на плане F1 (извещатели, табло, УДП, «Маяк» и др.) и собирает КЖ.
3. **Инженер может править результат** (переставить устройство, изменить трассу), после чего плагин **автоматически пересчитывает кабели и пересобирает КЖ** (команда пересчёта).
4. **Форма КЖ — стандартная:** обозначение кабеля, трасса (откуда — куда), марка и сечение кабеля, длина. Образец формы владелец не предоставил; при появлении образца форма уточняется.

## 2. Система марок эталона (для генератора)
Марка устройства: `<номер помещения><тип><цепь>.<номер>`; для табло к типу добавляется суффикс. Примеры серверной 1117 (префикс `3`) и кроссовой 1016 (префикс `1`).

| Марка (тип) | Устройство |
|---|---|
| `An` (`А1…А7`) | Модуль управления средствами пожаротушения |
| `UGn` | Источник вторичного электропитания резервированный |
| `PU-PT` | Пульт управления средствами пожаротушения |
| `yBTHz.n` | Извещатель пожарный дымовой оптико-электронный (3 варианта: обычный, за фальшпотолком, под фальшполом) |
| `BTМz.n` | Извещатель пожарный ручной ИПР 513-3М; устройство дистанционного пуска УДП 513-3М |
| `yBIALSn` | Оповещатель свето-звуковой |
| `yBIALn-У` | Табло «Газ (Порошок)! Уходи» |
| `yBIALn-Н` | Табло «Газ (Порошок)! Не входи» |
| `yBIALn-А` | Табло «Автоматика отключена» |
| `BGBz.n` | Извещатель охранный магнито-контактный |
| `MPPn` | Модуль порошкового пожаротушения |
| `ALn` | Цепи сигнальных шлейфов |
| `АЛСz.n` | Линия интерфейса |
| `Ln,Sn` | Цепи оповещения световое/звуковое |
| `Сn` | Пусковые цепи |

Пример состава серверной 1117 (лист `5A_00`): 5 дымовых извещателей (`3BTH1.1…1.5`), `3BTK1.2`, 2 охранных (`3BGB3.1/3.2`), ИПР/УДП `3BTM2.3`, табло `3BIAL1.1-У`, `3BIAL2.1-Н`, `3BIAL3.1-А`, 2 светозвуковых оповещателя `3BIALS2.1/2.2`, модуль `А3`. Кабельные линии на плане — полилинии слоя `АГПТ` (цвет 1 и 116 для разных цепей, по 0,5–4 м).

## 3. Кабели эталона (справочник)
| Назначение | Марка и сечение |
|---|---|
| Шлейфы | `КПСнг(А)-FRLS 1х2х0,5`, `КПСнг(А)-FRLS 1х2х0,7` |
| Интерфейс | `КИ-485-ПсЭнг(А)-HF 2х2х0,78` |

Какому типу цепи соответствует какая марка и сечение, в эталоне напрямую не указано: нужен справочник от владельца (раздел 6).

## 4. Модель данных в DWG (для пересчёта после правки инженером)
- **Устройство** — блок с атрибутами: `MARK` (например `3BTH1.5`), `TYPE`, `ROOM`, `LOOP`; на блоке XDATA приложения `AGPT` (идентификатор устройства).
- **Кабель** — полилиния на слое `АГПТ` с XDATA `AGPT`: `CABLE_ID` (обозначение в КЖ), `FROM` и `TO` (идентификаторы устройств), `TYPE` (марка и сечение).
- **Команда пересчёта** (имя уточнить, например `AGPT_CABLES`): читает устройства и кабели из чертежа, пересчитывает длину каждого кабеля по текущей геометрии (сумма длин сегментов плюс вертикальные участки по высотам установки), обновляет таблицу КЖ (`ACAD_TABLE`) и таблицу устройств на листах F1. Ручная правка таблицы КЖ допускается с пометкой в отчёте (как для спецификации).

## 5. Форма КЖ (стандартная, до получения образца)
| № | Обозначение кабеля | Трасса (откуда) | Трасса (куда) | Марка и сечение кабеля | Длина, м | Примечание |
|---|---|---|---|---|---|---|

Одна строка на кабельную линию; итог по маркам кабеля (суммарная длина) внизу журнала. Запас длины на разделку и монтаж в эталоне не виден: значение запаса — параметр проекта (вопрос владельцу).

## 6. Что нужно от владельца
1. **Нормативная база размещения**: правила расстановки извещателей, табло, УДП, оповещателей и ШПС для газового пожаротушения (в СП РК 2.02-102-2022 для газовых установок найден только п. 5.4.1.32: световое табло «Станция пожаротушения» у входа в станцию; размещение извещателей и оповещателей — по нормам пожарной сигнализации; нужен документ: номер СП РК или стандарт организации).
2. **Справочник кабелей**: какая марка и сечение для каких цепей (шлейф, интерфейс, оповещение, пуск, питание) и кому какой префикс/обозначение (`ALn`, `АЛСz.n`, `Ln,Sn`, `Сn`).
3. **Правила трассировки кабелей**: по стенам или потолку, высоты установки устройств, запас длины.
4. **Образец КЖ** (если есть), иначе утверждается форма раздела 5.
5. **Состав устройств по типу помещения** (в 1435 на листе F1 только часть выносок: серверная, кроссовая и архив отличаются).

## 7. Следствия для плана работ
- Автоматика F1 (устройства и кабели) — отдельный блок работ после библиотеки фрагментов: блоки устройств с атрибутами берутся из библиотеки, правила размещения — из п. 6.1.
- КЖ и таблица устройств — `ACAD_TABLE`, рассчитываются командой пересчёта; в автосверку (P8) входит проверка совпадения длин кабелей в КЖ с геометрией на плане.
