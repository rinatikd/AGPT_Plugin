# M1 — контракт интеграции GasCalc в AGPT.dll

**Статус:** технический контракт после статического аудита двух действующих расчётных путей. Это ещё не интеграция и не разрешение выдавать расчётные результаты. До прохождения M1 палитра оставляет расчётные/альбомные действия скрытыми.

## 1. Найденные активные legacy-пути

### Путь А — команда AGPT_CALC
src/AGPT_Stage3_Blocks_Full.cs

Команда читает XData VP, H, FH, CN, RHO0, затем вызывает MassCalc.Compute(ZoneData), KsidCalc.Compute(ZoneData) и MassCalc.SuggestVol(). MassCalc использует ln(100/(100-Cn)), упрощённую плотность, hard-coded multiplier и ограниченный Flamex-каталог. В случае нехватки наибольшего модуля SuggestVol возвращает 120 л, а не останавливается с требованием решения инженера.

### Путь Б — выпуск альбома
src/AGPT_Plugin_Drawings.cs

Collect.FromModel() читает другой набор XData (TM, K4, VTR, GOTV) и самостоятельно вызывает Calc.Mass(ZoneCalc). Здесь также используется логарифмическая формула, а остаток в трубах оценивается через неподтверждённые плотности. Collect.FromModel() при отсутствии реальных зон создаёт четыре демонстрационные комнаты. CalcDraw() снова вызывает legacy Calc.Mass().

Эти два пути должны быть сведены к одной функции расчёта на основе AGPT.Calc.GasCalc; оставлять две версии расчёта после M1 нельзя.

## 2. Поля: что можно перенести, а что нельзя выводить автоматически

| Текущие данные AGPT | Поле GasCalc | Правило миграции |
|---|---|---|
| ZoneCalc.Name / XData ZONE_NAME | RoomInput.Name | Переносить без изменения |
| ZoneCalc.Vp / XData VP | RoomInput.Volume | Переносить только если объём явно введён/подтверждён инженером; не вычислять его молча из площади и высоты |
| ZoneCalc.H / XData H | RoomInput.Height | Переносить; нулевые/невалидные значения — блокировка, не замена на 2.4 или 3.0 |
| ZoneCalc.Fh / XData FH | RoomInput.OpeningsArea | Переносить только если измеренная суммарная площадь проёмов известна |
| Нет надёжного поля | RoomInput.OpeningsPosition | Добавить явное значение: BottomAndTop / TopOnly / BottomOnly / Other. Не восстанавливать enum только по старому числу PParam; неизвестно, откуда оно было взято |
| ZoneCalc.Tm / XData TM | RoomInput.TMinC | Старое значение/дефолт 25 °C не считать нормативно подтверждённой минимальной температурой; требуется проектное значение |
| Нет надёжного поля | RoomInput.DeltaVolume | Если расчётный объём для δ отличается от Vр, хранить его отдельно; иначе оставить null только после подтверждения, что δ использует тот же объём |
| ZoneCalc.K4 / XData K4 | RoomInput.Fire | **Не переносить K4 как число.** Добавить явный класс/тип горючего (ClassBHeptane / ClassAOther / ClassAPaperRolls); K4 вычисляет GasCalc по Fire |
| ZoneCalc.Cn / Rho0 / Gotv | GotvSpec | Не использовать как произвольные ручные overrides. Выбрать версионированную спецификацию ГОТВ по каталогу производителя/норме; зафиксировать источник, единицы и редакцию |
| Project data | ProjectSettings.AltitudeM / K3Mode | Высота — обязательное свойство объекта/проекта. Для 347 м вопрос K3=0.96 против интерполяции 0.955 остаётся открытым; решение должно быть явной настройкой с записью в расчёт |
| ZoneCalc.Vtr / XData VTR | RoomInput.PipeVolume | Текущее значение VTR может быть дефолтным, поэтому переносить только из фактической модели трубопроводов |
| Нет надёжного поля | RoomInput.PResidualAbsMpa | Без остаточного абсолютного давления из гидравлического расчёта нельзя считать Mтр достоверным. При Vтр>0 и неизвестном давлении выпуск/приёмка блокируется |
| Нет подтверждённого источника | Module.ResidualKg | Mб брать только из эксплуатационного документа конкретного типа/модели модуля. Ноль допустим только как явно подтверждённое значение, а не default |
| Нет пользовательского решения в модели | RoomInput.ChosenModules | Когда GasCalc возвращает NeedsEngineerDecision, сохранить выбранные инженером имена модулей отдельно по каждой комнате; не подменять автоматическим набором |

## 3. Коллизии каталогов и недопустимые defaults

Сейчас Stage3 содержит ModuleData.Cat (Flamex, 40–120 л), тогда как GasCalc имеет отдельный DefaultCatalog() и собственную модель Module. Эти каталоги не взаимозаменяемы. M1 должен:
- выбрать один версионированный производитель/каталог для конкретного проекта;
- хранить номинальную заправку, остаток Mб, тип/объём, допустимость применения, datasheet ID/версию и хэш источника;
- не смешивать Flamex и Proffex;
- вернуть список вариантов инженеру, если один модуль недостаточен;
- блокировать расчёт/выпуск, если ни один проверенный каталог не загружен.

Недопустимо переносить старые defaults K4=1.05, Tm=25, Vtr=0.005, Rho0=7.28, Fh=0.011 как будто они пришли из чертежа. Отсутствующее или устаревшее входное значение должно получать статус MISSING/UNCONFIRMED и запрашиваться у инженера.

## 4. Единственный расчётный use case

Создать единственную точку входа GasCalculationService.Calculate(ZoneCalcInput, ProjectCalcSettings, GotvSpec, ModuleCatalog):

1. Проверить полноту, единицы и конечность всех входов.
2. Вернуть явный список недостающих/неподтверждённых значений; не вычислять результат при блокирующих пробелах.
3. Сформировать RoomInput без скрытых defaults и вызвать GasCalc.Compute.
4. Сохранить CalcResult + все входные значения + версии нормы/каталога + warnings + source hashes.
5. Если NeedsEngineerDecision=true, остановить формирование спецификации/альбома для этой комнаты и вывести Candidates; после выбора сохранить ChosenModules и выполнить расчёт повторно.
6. Если Warnings содержит отсутствующее остаточное давление, запрещённую негерметичность или неподтверждённый Mб — отобразить блокирующее предупреждение в отчёте согласно severity policy; не маркировать комплект расчётно завершённым.
7. Перед записью XData/таблиц провести все проверки; транзакция DWG должна откатываться при неполном наборе решений.

Обе старые команды (AGPT_CALC и AGPT_CALC_DRAW) должны вызывать этот use case. Ни одна не должна сохранять отдельную legacy-формулу.

## 5. Демонстрационные данные и проектные реквизиты

Collect.FromModel() не должна автоматически создавать демо-комнаты. При отсутствии реальных зон:
- команда предлагает ввести/импортировать зоны;
- при отказе корректно завершает операцию без изменения чертежа;
- ProjectData не должен автоматически подставлять организацию, фамилии, ГИПа, шифр и адрес эталонного детского сада в новый проект;
- исходный DEMO допускается только как явно выбранный отдельный fixture/test DWG и не должен попасть в производственный расчёт.

## 6. План безопасного внедрения

**M1a — данные и статические guards**
- расширить модель ZoneCalc явными полями OpeningsPosition, FireKind, DeltaVolume, altitude/K3Mode reference, PResidualAbsMpa, validated source flags и ChosenModules;
- добавить validation result с blocking vs non-blocking findings;
- убрать silent demo fallback из Collect.FromModel;
- оставить прежние команды расчёта заблокированными до завершения M1b.

**M1b — единый GasCalc path**
- добавить src/Calc/GasCalc.cs в явные Compile Include AGPT.csproj (в проекте EnableDefaultCompileItems=false);
- внедрить GasCalculationService и заменить обе legacy реализации;
- удалить автоматический SuggestVol(120) fallback и оба расчётных пути legacy;
- обеспечить стабильный каталог и модульные остатки из datasheet.

**M1c — интеграционные тесты**
- сохранить текущие GasCalc golden tests;
- добавить mapping tests old XData → required fields, missing field stops, enum mapping, 347m K3 setting, residual pressure, module selection and no-demo behavior;
- проверять тот же исходный расчётный модуль, который включается в AGPT.dll;
- добавить отчёт о значениях входов/источников и повторяемости результата.

**M1d — AutoCAD E2E**
- сборка x64 against AutoCAD 2026 ObjectARX assemblies;
- NETLOAD только в disposable DWG;
- тест пустой модели, тест с одной валидной комнатой, тест неизвестного пожарного класса, отсутствующего давления и выбора модулей;
- проверить отсутствие изменений DWG при блокирующей ошибке;
- затем отдельный owner review перед включением расчётных кнопок.

## 7. Критерий завершения M1

M1 PASS только когда:
- обе команды используют единственный GasCalc use case;
- AGPT.dll реально содержит интегрированный GasCalc;
- нет скрытых demo/default значений и старых legacy formulas;
- модульный каталог имеет подтверждённую версию и источник;
- решения инженера сохраняются по комнате;
- нормативные golden + mapping + regression tests проходят;
- AutoCAD 2026 disposable DWG E2E подтверждает правильную транзакционность и отсутствие побочных изменений при STOP.

До этого AGPT расчётный выпуск остаётся NO-GO.
