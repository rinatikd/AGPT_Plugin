# AGPT — проверка минимальной палитры AutoCAD 2026

**Статус:** Draft PR #1; исходный код проверен статически. Сборка с реальными ObjectARX DLL AutoCAD 2026 и запуск внутри AutoCAD пока НЕ подтверждены.

## Границы теста

- Только отдельный Lab/тестовый профиль и новый disposable DWG.
- Только ручная загрузка через NETLOAD.
- Не запускать install_bundle.bat, не создавать bundle и не включать автозагрузку.
- Не открывать рабочий DWG и не выполнять расчёты/выпуск документации.
- Не менять Production, системные настройки или конфигурацию AutoCAD.

## Что подтверждено по исходникам PR

1. AGPT.csproj — net8.0-windows, x64, WinForms и явный Compile Include.
2. Новый src/AgptPalette.cs включён в Compile Include.
3. Команды AGPT_UI и AGPT_PANEL объявлены в палитре.
4. Кнопки зоны вызывают AGPT_ZONE и AGPT_ZONE_LIST; обе команды реально объявлены в src/AGPT_Stage3_Blocks_Full.cs, который включён в проект.
5. README не предлагает включать расчётную кнопку до M1.
6. build.bat обнаруживает MSBuild через vswhere с параметром -prerelease, что позволяет найти Preview/Insider установки Visual Studio. Это не доказывает, что сборка прошла в целевой среде.

## Ограничение расчётного ядра — M1

Файл src/Calc/GasCalc.cs присутствует в репозитории, но в текущем AGPT.csproj отсутствует Compile Include для него. Проект tests/GasCalc.Tests отдельно компилирует этот файл как Link и тестирует его отдельно; это не доказывает, что GasCalc попадает в AGPT.dll.

Следовательно, до отдельного интеграционного PR:
- не считать GasCalc активным расчётным движком DLL;
- не активировать расчётные кнопки/команды в палитре;
- не утверждать, что legacy AGPT_CALC / AGPT_HYDRO2 используют GasCalc;
- не использовать старые расчётные результаты как подтверждение M1.

## Ручной smoke test (только после локальной сборки владельцем)

1. На машине с AutoCAD 2026 и .NET SDK 8 проверить наличие:
   - C:\Program Files\Autodesk\AutoCAD 2026\AcCoreMgd.dll
   - AcDbMgd.dll и AcMgd.dll в том же каталоге.
2. Из корня репозитория выполнить:
   - build.bat "C:\Program Files\Autodesk\AutoCAD 2026"
3. Сохранить полный build log и SHA-256 итоговой AGPT.dll.
4. Запустить AutoCAD 2026, создать новый пустой тестовый DWG и сохранить его под отдельным именем в Lab-каталоге.
5. Выполнить NETLOAD и выбрать собранную AGPT.dll.
6. Выполнить AGPT_UI, затем AGPT_PANEL. Должна открыться одна палитра; повторный вызов не должен создавать дубликат.
7. Проверить, что метка активного чертежа показывает имя тестового DWG. После переключения документа нажать «Обновить сведения» и проверить новое имя.
8. Нажать «Создать / выбрать зону». Команда AGPT_ZONE должна быть найдена AutoCAD и показать свой штатный prompt.
9. Завершить команду безопасным отменяющим действием (Esc). На этом UI smoke test завершён; не создавать тестовую геометрию в рабочем файле.
10. Открыть список зон через AGPT_ZONE_LIST. Команда должна быть найдена и корректно обработать пустую модель.
11. Закрыть тестовый DWG без сохранения, если были внесены любые изменения тестовой командой.

## Критерии PASS

- Build завершился с exit code 0 с ObjectARX DLL именно AutoCAD 2026.
- Итоговая DLL — x64, net8.0-windows и содержит команды AGPT_UI / AGPT_PANEL.
- NETLOAD завершился без ошибок зависимостей.
- Палитра открывается один раз и не блокирует AutoCAD UI.
- Команды AGPT_ZONE и AGPT_ZONE_LIST разрешаются в AutoCAD.
- В тестовом DWG нет неожиданных изменений после проверки.
- Сохранены build log, DLL hash, версия AutoCAD и точный commit SHA.

**PASS исходников не равен PASS сборки. PASS сборки не равен PASS AutoCAD smoke test.** До получения этих evidence PR остаётся Draft.
