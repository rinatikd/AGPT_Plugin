# Требования к сборке альбома АГПТ (решения владельца, 2026-11-06)

Результат пошагового разбора пунктов сравнения «выход плагина — эталон МГИМО». Источник решений — ответы владельца в диалоге. Документ имеет приоритет над `docs/AGENT_TASKS.md` и `docs/PRIORITIES.md` там, где они расходятся.

## Уровни требований
- **Обязательно** — без этого комплект не выпускается, проверяется автоматически (пакет P8).
- **Целевое** — делаем по эталону, допускается отклонение с пометкой в отчёте.
- **Справочное** — образец, не проверяется.
- **Исключено** — не делаем.

## Состав комплекта
| ID | Требование | Уровень |
|---|---|---|
| A1 | Состав листов по эталону МГИМО: T1–T9 (`AGENT_TASKS.md`, раздел 4.4) | Обязательно |
| A2 | Расчётный лист на каждое помещение (в эталоне 5 штук); принято по умолчанию, владельцем не оспорено | Обязательно |
| C3 | **Аксонометрия** — обязательный лист (в эталоне нет: сверяется по содержанию — трассы, диаметры, позиции совпадают с планом и расчётом; оформление по правилам остальных листов). Лист **«КЖ»** — необязательный, включается флагом | Обязательно / Целевое |
| B2 | Размещение: в модели, рамки с масштабом вокруг планов, как в эталоне | Обязательно |
| B1 | Рамка и штамп — внешний блок `blocks/MMX_ШТАМП.dwg`, не менять; плагин выводит в командную строку, какой блок загружен (или «запасная рамка») | Целевое |

| ID | Требование | Уровень |
|---|---|---|
| C1 | Планы: **полная автоматика** — модули, разводка трубопроводов, насадки, выноски строит плагин; инженер проверяет результат. Нужны геометрия помещений и препятствий и гидравлическая проверка | Обязательно |
| C2 | Расчётная схема и схема подключения строятся из той же трассы и расчёта | Обязательно |
| C4 | Масштаб плагин выбирает по размеру плана из ряда (в эталоне 1:40 и 1:48, полный ряд утвердить) | Обязательно |
| C5 | Выноски (MULTILEADER) на планах и схемах | Обязательно |
| C6 | Сквозная нумерация модулей (1МРТ1…7МРТ1), одинаковая на плане, в расчёте и в спецификации | Обязательно |
| C5а | Размеры (DIMENSION) | Целевое (по желанию) |

## Расчёт и спецификация
| ID | Требование | Уровень |
|---|---|---|
| C8 | Расчёт массы ГОТВ — `GasCalc` по СП РК 2.02-102-2022 (`docs/CALC_SPEC_RK.md`). Коэффициенты **строго по норме, ручное переопределение K3, K4, ρготв, П запрещено**. Вход (вид горючего, положение проёмов, высота объекта, температура) задаётся данными, не коэффициентами | Обязательно |
| D1 | Таблицы: полнота строк и колонок по профилям эталона («Исходные данные» 8 колонок, «Результаты» 9, «Трубопроводная разводка» 7, спецификация 9) | Обязательно |
| D2 | Все таблицы — объекты `ACAD_TABLE`, как в эталоне | Обязательно |
| D3 | Количества и массы в спецификации — из расчёта; **ручная правка разрешена с пометкой в отчёте** | Обязательно |
| D4 | Когда одного модуля не хватает, набор модулей выбирает **инженер по каждому помещению**; без молчаливого значения по умолчанию (движок возвращает варианты «меньше модулей» и «меньше заправки» и ждёт выбора) | Обязательно |

## Технические артефакты
| ID | Требование | Уровень |
|---|---|---|
| E1 | Наложения текста, таблиц и выносок друг на друга и на штамп: **предупреждение в отчёте**, выпуск не блокируется | Целевое |
| E2 | Нет зон в модели: плагин **предлагает ввести помещения вручную, иначе останавливается**; тихой подстановки демо-данных нет; фамилии, шифр, организация — из данных проекта | Обязательно |
| E3 | Шрифты: **shx (GOST type B) независимо от эталона** (отступление от эталона, где `GOST_Common Italic`, `isocpeur`); если шрифта нет в системе — предупреждение (у владельца AutoCAD подменяет GOST type B на simplex.shx) | Целевое |
| E4–E5 | Слои и веса линий создаются автоматически по эталону (`АГПТ`, `АСПТ`, `Формат`, `О_Формат`, `RC-Таблицы` и др.; `reference_spec/`) | Обязательно |
| E6 | PDF и печать — **не нужны**, только DWG | Исключено |
| E7 | Повторный запуск команды альбома: **каждый раз спрашивает**, что делать с прежним альбомом | Обязательно |

## Следствия для реализации
1. Из `GasCalc` убрать поля переопределения (`K3Override`, `K4Override`, `PiOverride`, `RhoResidual`); ρготв определяется остаточным давлением из гидравлического расчёта; правило K3 между строками таблицы (ближайшая нижняя строка или интерполяция) — настройка проекта, а не помещения. Добавить правило подбора «спросить инженера».
2. Спецификация: журнал ручных правок (что, кем, когда) попадает в отчёт.
3. Планы (C1) требуют выгрузки геометрии эталонных планов (пакет P6) и модуля трассировки; приёмка — гидравлика (время выпуска, давление у насадков) по таблицам эталона.
4. Проверка E3 (шрифты) исключается из автосверки с эталоном; проверяются имена и высоты стилей.
5. Автосверка (P8) проверяет «Обязательно» и «Целевое» отдельно: невыполненное «Обязательно» блокирует признание комплекта собранным.

## Открытые вопросы
1. Ряд масштабов для автоматического выбора (кроме 1:40 и 1:48).
2. Правило K3 для высоты между строками таблицы Д.11 (для Астаны 347 м: 0,96 или 0,955).
3. Источник Mб (остаток в модуле Proffex) и способ определения ρготв по давлению остатка.
4. Какие данные плагин берёт из модели для автотрассировки (потолки, балки, воздуховоды, фальшпол) и как инженер вводит недостающее.
5. Подтвердить A2 (расчётный лист на каждое помещение).
